# SecPocket 1.0

**Cybersecurity frameworks, in your pocket.**

The first public release of SecPocket: 77 field briefs across 14 domains, built for consultants who need the right framework answer in front of a client — offline, searchable and fast.

## Highlights

- **77 briefs across 14 domains** — NIST CSF 2.0, NIST SP 800-53, ISO/IEC 27001, ANSSI, BSI, NCSC CAF, CIS Controls, PCI DSS, SWIFT CSP, NIS2, DORA, IEC 62443, OWASP Top 10:2025, ASVS 5.0, MITRE ATT&CK, WPA3, 5G, post-quantum cryptography and more.
- **26 essential briefs** for the frameworks that come up first in engagements.
- **Crown jewels, core pillars and client playbooks** on every brief.
- **Accent-insensitive search**, domain filters and locally saved briefs.
- **Fully offline** — no permissions, no accounts, no analytics, no network access.
- **Tiny install** — about 124 KB, Android 8.0+.

## Install

1. Download `SecPocket-1.0.apk`.
2. Open it from your file manager and allow installation from that source if prompted.
3. If Play Protect warns about an unknown developer, choose **More details → Install anyway**. The APK is self-signed for direct distribution.

Or with ADB:

```powershell
adb install -r SecPocket-1.0.apk
```

## Notes

- **Android 8.0 (API 26) or newer.** Target SDK 34, compiled with SDK 35.
- **No permissions at all**, including no internet access.
- Saved briefs stay in the app's private storage; uninstalling removes them.
- The catalog is embedded in the APK. No content is downloaded at runtime.
- The briefs are original field summaries, not official standards text or legal advice. Verify current editions before relying on them in an engagement.
